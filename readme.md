## 💇 Sobre o projeto

O **Code e Corte** é um projeto de **Front End desenvolvido em grupo durante a faculdade**, voltado para uma **rede de salões de beleza**.

O projeto trabalha a parte visual da aplicação, com páginas e áreas destinadas aos diferentes usuários do sistema, além da apresentação dos salões e dos serviços.

## 🎯 Objetivo

Aplicar na prática os conhecimentos de desenvolvimento Front End trabalhados durante a graduação, desenvolvendo uma interface organizada para uma rede de salões de beleza.

- Página inicial
- Cadastro
- Login
- Perfil
- Meus agendamentos
- Salão
- Área administrativa
- Área do dono
- Área do funcionário

## 👥 Projeto em grupo

Projeto desenvolvido em grupo como atividade acadêmica do curso de **Engenharia de Software**.

## 📚 Contexto

Projeto desenvolvido durante a graduação com foco na aplicação prática de conceitos de **Front End**, estruturação de páginas e criação de interfaces para uma rede de salões de beleza.
