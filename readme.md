## 💇 Sobre o projeto

O **Code e Corte** é um projeto de **Front End desenvolvido em grupo durante a faculdade**, voltado para uma **rede de salões de beleza**.

A aplicação possui diferentes áreas de acesso, permitindo representar experiências para clientes, donos, funcionários e administradores.

O projeto foi desenvolvido como atividade acadêmica do curso de **Engenharia de Software**, colocando em prática conhecimentos de criação de páginas, organização de interfaces e estilização com HTML e CSS.

---

## 🎯 Objetivo

Desenvolver uma interface para uma rede de salões de beleza, aplicando na prática conhecimentos de **HTML e CSS**, organização de páginas e criação de interfaces para diferentes perfis de usuário.
